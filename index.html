Common technical questions

Safety limits, storage mechanisms, and Windows compatibility details.

How does App Guard protect my system? +

App Guard detects the CleanSweep executable and Windows system directories, locking them against accidental deletion during sweeps.

Does CleanSweep require an installation procedure? +

CleanSweep requires no installer. Run the single executable from any folder or external storage device.

Can I choose which file extensions are preserved? +

Each folder lists detected file extensions. Uncheck any format to preserve those files during cleanup.

Where is my cleanup history stored? +

All cleanup metrics stay in a local SQLite file. CleanSweep never makes external network connections.
